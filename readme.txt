Complete WooCommerce Cart Abandonment Recovery with Email, WhatsApp, SMS, Telegram & Analytics.

== Description ==

Cart Abandonment Recovery Pro helps WooCommerce store owners recover lost sales through automated multi-channel recovery campaigns.

= Features =
* Automated email recovery sequences with open/click tracking
* WhatsApp recovery (UltraMsg, WhatsApp Business API, Twilio)
* SMS recovery (Twilio, Vonage)
* Telegram bot recovery
* 1-click cart recovery links with token authentication
* Unique coupon code generation per recovery attempt
* Rule engine for conditional campaign logic
* Analytics dashboard with charts and KPIs
* Product-level abandonment reports
* GDPR-ready consent checkbox
* Admin email notifications

== Installation ==

1. Upload plugin folder to `/wp-content/plugins/`
2. Activate via the WordPress Plugins menu
3. Go to **Cart Recovery** in the admin sidebar
4. Configure settings and create campaigns
